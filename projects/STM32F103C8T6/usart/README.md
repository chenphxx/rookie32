# usart

## 实现

`USART`即通用`同步异步收发器`, 在嵌入式开发当中常用其实现与外部设备间的双全工数据交换; 通常需要两个引脚`TX`/`RX`, RX用于接收, TX用于发送, 两个设备之间, TX与RX连接, RX与TX连接, 注意不要连接错了 

本例中, 每500ms会通过`usart1`向串口发送字符串`Hello, USART1!`
