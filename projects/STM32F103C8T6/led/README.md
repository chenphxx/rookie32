# led

点亮一个led之于嵌入式, 就像hello world之于编程语言 

## 实现

在这里我们使用`STM32F103C8T6`最小系统, 该开发板中PC13引脚已经接了一个led 

1. 使能`APB2`上的`GPIOC`时钟 

2. 初始化`PC13`引脚 

3. 主函数中通过循环计数模拟延时以及切换高低电平, 实现led闪烁的功能

这个三个步骤也是嵌入式开发当中的一般步骤: 

即找到对应引脚的总线, 使能该总线->根据实际需求定义引脚的结构体->调用初始化函数对该引脚进行初始化->主函数中实现项目逻辑 

## 说明

点亮PC13, 仅使用了`RCC`与`GPIO`两个外设驱动, 因此`Library/`中删掉了点亮led灯不需要的所有`.h`与`.c`文件, 并且在`Main/stm32f10x_conf.h`中也将未使用的外设驱动头文件注释掉了
