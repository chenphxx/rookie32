# delay

## 循环计数延时

在上一个例子`led`中, 我们点亮了开发板上的PC13引脚, 并且通过循环计数实现了延时的功能, 让led闪烁起来, 尽管实现起来很简单, 也能正常工作 

```c
for (int i = 0; i < 1000000; i++);
```

但是这种延时的方式还是存在着缺陷的: 

- 没有办法实现精确的延时, 例如500ms 

- 同一段延时代码, 在不同的设备上运行, 表现出来的效果可能不一样 

- 会占用CPU, 执行延时的时候CPU不能做其他工作

因此, 我们需要一种更精确, 并且不占用CPU的延时的实现方法, 我们可以通过SysTick系统定时器来实现 

## SysTick系统定时器延时

系统定时是一个24位, 向下递减的计数器, 存放在重装载寄存器中, 当寄存器归0, 系统定时器执行一次中断, 执行中断服务程序中的函数
